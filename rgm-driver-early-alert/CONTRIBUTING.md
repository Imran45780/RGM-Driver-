# Contributing

Before submitting changes, confirm that you are authorized to share or modify this script.

- Keep changes focused and explain the behavior being changed.
- Test in an approved environment, not against live operational transactions.
- Verify R4G, Dockmaster, and FMC field mappings after UI changes.
- Include test notes for each affected load type and threshold.
- Do not commit credentials, appointment identifiers, internal screenshots, or confidential operational details.

The script is experimental and relies on visible text and DOM structure; changes should document any new assumptions.
